# Конфигурация guard-daemon

Это минимальный авторитетный справочник переменных окружения. Демон проверяет
конфигурацию при запуске; отдельной команды локальной проверки нет.
Файл `.env` использует только строгие строки `NAME=value`; формы `NAME: value`
и `export NAME=value` отклоняются до разбора значений.

## Общие поля

| Поле | Обязательность и значение |
|---|---|
| `DRY_RUN` | Необязательно, по умолчанию `true`. Значение `false` явно включает live-режим. |
| `SOURCE_ADDRESS` | Обязательный публичный адрес наблюдаемой роли source. |
| `SPONSOR_ADDRESS` | Обязательный публичный адрес роли sponsor, оплачивающей gas. |
| `DESTINATION_ADDRESS` | Обязательный публичный адрес безопасной роли destination. |
| `ENABLED_NETWORKS` | Обязательный список сетей через запятую, только в нижнем регистре. Значения по умолчанию нет. |
| `SOURCE_PRIVATE_KEY` | Обязателен только в окружении live-процесса при `DRY_RUN=false`. Из `.env` не загружается. |
| `SPONSOR_PRIVATE_KEY` | Обязателен только в окружении live-процесса при `DRY_RUN=false`. Из `.env` не загружается. |
| `RESCUER_ARTIFACT` | Необязательно, по умолчанию `artifacts/contracts/RescuerV2.json`. |
| `RPC_READ_TIMEOUT` | Необязательно, по умолчанию `10s`. |
| `STATE_DIRECTORY` | Необязательно, по умолчанию `state`. Непустой нормализованный путь без NUL. |
| `WATCH_LOOKBACK_BLOCKS` | Необязательно, по умолчанию `64`. Строго положительное десятичное целое `uint64`, не больше `10000`. |
| `MAX_TRANSACTION_COST_WEI` | Необязательно, по умолчанию `10000000000000000`. |
| `CUMULATIVE_BUDGET_WEI` | Необязательно, по умолчанию `50000000000000000`. |
| `SPONSOR_MIN_BALANCE_WEI` | Необязательно, по умолчанию `20000000000000000`. |
| `RATE_LIMIT_PER_MINUTE` | Необязательно, по умолчанию `6`. |

Адреса source, sponsor и destination должны быть ненулевыми и попарно
различными. Поддерживаются сети `base`, `ethereum`, `arbitrum`, `optimism`,
`polygon`, `ink`, `scroll`, `linea`, `metis` и `bnb`. Пустое имя, неизвестная
сеть и имя не в нижнем регистре отклоняются. Демон подключается только к сетям,
явно перечисленным в `ENABLED_NETWORKS`.

Поля стоимости, суммарного бюджета, минимального баланса и ограничения частоты
сейчас разбираются и строго проверяются как типизированные входы политики.
Принудительное соблюдение бюджета и ограничения частоты относится к Task 08.
Эта предварительная задача не разрешает эксплуатацию в рабочей среде.

## Политика state и backfill

При первом запуске без checkpoint демон сканирует ограниченное окно ретроспективного просмотра до согласованного финализированного блока. Размер окна задаёт `WATCH_LOOKBACK_BLOCKS`; сканирование не начинается молча с текущего блока и не выходит за настроенную границу.

Локальное состояние обязательно для восстановления после сбоя. `STATE_DIRECTORY`
задаёт его каталог, даже если используется значение по умолчанию. Путь должен уже
быть в нормализованной форме, не быть пустым и не содержать NUL; значение пути не
выводится при форматировании `Runtime` и в ошибках проверки конфигурации.
Повреждение state, несовпадение сохранённой идентичности сети или конфигурации и невозможность получить эксклюзивную блокировку являются fail-closed ошибками запуска.
Существующий пустой файл или state без служебной схемы также считается повреждённым
и никогда не переинициализируется автоматически. Для намеренного первого запуска
оператор удаляет такой файл только при остановленном демоне и после проверки, что
восстанавливать незавершённую работу не требуется.

Checkpoint продвигается только после durable `Ack` соответствующих candidates.
Поэтому восстановление после сбоя повторяет неподтверждённую работу, а checkpoint
не опережает её надёжное подтверждение.

## Поля сети

Для каждой включённой сети `<N>` заменяется её именем в верхнем регистре.
Например, для `base` используется суффикс `BASE`. Точные шаблоны и их
обязательность:

| Шаблон поля | Обязательность и значение |
|---|---|
| `RPC_READ_1_HTTP_<N>` | Обязательный HTTP URL первого провайдера чтения. |
| `RPC_READ_1_WS_<N>` | Обязательный WebSocket URL первого провайдера чтения. |
| `RPC_READ_1_TRUST_DOMAIN_<N>` | Обязательный домен доверия первого провайдера чтения. |
| `RPC_READ_2_HTTP_<N>` | Обязательный HTTP URL второго провайдера чтения. |
| `RPC_READ_2_WS_<N>` | Обязательный WebSocket URL второго провайдера чтения. |
| `RPC_READ_2_TRUST_DOMAIN_<N>` | Обязательный домен доверия второго провайдера чтения. |
| `RPC_BROADCAST_HTTP_<N>` | Обязательный и допустимый только при `DRY_RUN=false` отдельный RPC отправки. |
| `RESCUER_MANIFEST_<N>` | Обязательный путь к доверенному манифесту сети. Значения по умолчанию нет. |
| `TOKEN_MODE_<N>` | Необязательно, по умолчанию `known-only`. |
| `TOKEN_ALLOWLIST_<N>` | Обязателен и допустим только при режиме `allowlist`. |

Поля, обязательные в обоих режимах, повторяются отдельно для каждого суффикса:

```dotenv
RPC_READ_1_HTTP_<N>=https://YOUR_READ_RPC_1
RPC_READ_1_WS_<N>=wss://YOUR_READ_RPC_1
RPC_READ_1_TRUST_DOMAIN_<N>=YOUR_INDEPENDENT_TRUST_DOMAIN_1
RPC_READ_2_HTTP_<N>=https://YOUR_READ_RPC_2
RPC_READ_2_WS_<N>=wss://YOUR_READ_RPC_2
RPC_READ_2_TRUST_DOMAIN_<N>=YOUR_INDEPENDENT_TRUST_DOMAIN_2
RESCUER_MANIFEST_<N>=PATH_TO_YOUR_TRUSTED_MANIFEST
```

RPC отправки добавляется только при `DRY_RUN=false`:

```dotenv
RPC_BROADCAST_HTTP_<N>=https://YOUR_SEPARATE_BROADCAST_RPC
```

Два провайдера чтения должны иметь разные HTTP URL, WebSocket URL и домены доверия.
Совпадение любого из них отклоняется как отсутствие независимости. Broadcast URL
должен отличаться от обоих HTTP URL чтения. Значения RPC
URL не выводятся в сообщениях об ошибках и журналах: они редактируются, чтобы не
раскрывать данные доступа. WebSocket URL задаётся отдельно для каждого
провайдера чтения. RPC отправки не участвует в чтении и аттестации по
финализированному блоку.

`RESCUER_MANIFEST_<N>` указывает на локальный доверенный манифест деплоя
конкретной сети. Значения по умолчанию у него нет.

## Политика токенов

`TOKEN_MODE_<N>` необязателен и по умолчанию равен `known-only`:

| Режим | Семантика |
|---|---|
| `known-only` | Безопасный режим по умолчанию: разрешены только известные системе токены. |
| `allowlist` | Разрешены только адреса из обязательного `TOKEN_ALLOWLIST_<N>`. |
| `all` | Явное согласие обрабатывать неизвестные токены; само по себе не разрешает эксплуатацию в рабочей среде. |

`TOKEN_ALLOWLIST_<N>` задаётся списком адресов через запятую и допустим только
при `TOKEN_MODE_<N>=allowlist`:

```dotenv
TOKEN_MODE_<N>=allowlist
TOKEN_ALLOWLIST_<N>=0xYOUR_TOKEN_ADDRESS_1,0xYOUR_TOKEN_ADDRESS_2
```

## Порядок безопасного запуска

В live-режиме запуск выполняется строго в таком порядке:

1. Локально проверяются типы, обязательные поля, адреса, сети и политики.
2. Загружается доверенный манифест каждой включённой сети.
3. Два независимых HTTP-провайдера чтения должны согласовать финализированный блок и результат аттестации runtime.
4. Открывается и проверяется persistent state каждой сети; повреждение,
   несовпадение привязки или занятая блокировка останавливают запуск.
5. Только после согласования и проверки state создаются подписывающие компоненты
   source и sponsor, а их адреса сверяются с `SOURCE_ADDRESS` и
   `SPONSOR_ADDRESS` до первой подписи.
6. Для отправки используется отдельный RPC.

Любая ошибка или расхождение завершает запуск до подписания. При запуске
сетевого поколения watcher отдельно открывает runtime finalized quorum,
проверяет durable cursor и выполняет backfill до создания рабочей subscription.

При `DRY_RUN=true` демон загружает только публичную конфигурацию и доверенный
манифест. Строки ключей в `.env` пропускаются, а значения ключей процесса не
разбираются и не сохраняются в конфигурации. Демон не создаёт рабочий signer или
broadcaster, не подписывает и не отправляет транзакции. После подключения к сети
во время работы он наблюдает за событиями и выполняет только планирование для
чтения и `EstimateGas`.

## Удалённые настройки

Следующие прежние настройки не поддерживаются и должны быть удалены из
операторского окружения:

- `RESCUER_*` в прежнем значении адресов деплоя, например `RESCUER_BASE`; это не относится к актуальным `RESCUER_ARTIFACT` и `RESCUER_MANIFEST_<N>`.
- Старые `RPC_URL_*`.
- `RESCUE_TOKENS`.
- `TOKENS_TO_SWEEP`.
- `CLAIM_*`.

Неизвестное или удалённое поле не следует считать включённой возможностью.

## Безопасные ошибки

Ошибка конфигурации называет поле и причину отказа, но не его значение. Приватные
ключи, подписи, данные авторизации, данные доступа RPC и полные RPC URL не должны
появляться в ошибках или журналах. Отсутствующий манифест, отсутствие
независимости провайдеров, ошибка аттестации по финализированному блоку или
несовпадение адреса подписывающего компонента приводят к fail-closed остановке
до подписания и отправки.
