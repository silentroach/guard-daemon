# Отчёты независимого ревью

В этой папке каждая завершённая задача сохраняет публичный отчёт независимого ревью по шаблону [`../review-template.md`](../review-template.md).

Имена файлов:

- `01-foundation.md`
- `02-go-architecture.md`
- `03-contract-hardening.md`
- `04-deployment-attestation.md`
- `05-config-dry-run.md`
- `06-watcher-rpc.md`
- `07-rescue-coordinator.md`
- `08-abuse-observability.md`
- `09-security-validation.md`
- `10-operations-release.md`
- `11-final-release.md`

Отчёт не содержит секреты, реальные transaction payloads, incident-specific identifiers, private RPC URL и персональные данные. Статус `ПРОЙДЕНО` допускается только после closure pass по всем изменениям проверяемых файлов.
